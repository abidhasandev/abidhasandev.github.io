# Abid Hasan — Portfolio V9 (premium redesign)

## What changed
- Hero: portrait with two counter-rotating icon orbits (no square panel behind the portrait).
- Same dark navy + lime identity, but headings are now sentence case, with calmer typography and more space.
- New: stats strip, "Tools I build with" grid, Experience & education timeline (from your CV), quick-pick options in the contact form, copy-email button, active nav highlight.
- Projects: same live sites and hover-scroll previews, now in a staggered layout. Fixed the empty paragraph bug in the old project cards.
- Performance: PNG images converted to WebP (assets went from ~10 MB to ~1 MB). Devicon CDN removed.
- Accessibility: skip link, keyboard focus styles, reduced-motion support.

## GitHub update
Extract this ZIP and upload `index.html`, `README.md` and the complete `assets` folder to the root of your repository, replacing the old files. The old `.png` portraits and screenshots are no longer used.
